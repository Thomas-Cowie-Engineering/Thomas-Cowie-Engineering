# 💫 About Me:
Hello, I'm Thomas Cowie, a passionate Electrical and Electronic Engineering student at the University of Sheffield.
 
I'm an FPGA and chip design enthusiast, experienced in taking designs from RTL through verification and synthesis to working hardware, including FPGA implementation and tapeout via Tiny Tapeout.

I primarily use Github to show of my projects, see my pinned repositories to check out what I've made !
